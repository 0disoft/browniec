Brownie C는 Fairy C의 문법 감각을 그대로 가져오면서도, 가상 머신(VM) 안에서 결정적이고 안전하게 실행되는 범위로 문법을 간추린 언어입니다.

## 1. 파일 시작과 변수 선언 (`let`, `var`)

모든 `.brc` 파일은 맨 위에 `module main;` 선언으로 시작합니다. 변수를 선언할 때는 재할당 여부에 따라 `let`과 `var`를 씁니다.

```c
module main;

fn i32 main() {
    let i32 base = 70;      // 한 번 정하면 바꿀 수 없음
    var i32 bonus = 5;      // 나중에 bonus = ... 처럼 수정 가능
    bonus = bonus + 2;
    return base + bonus;    // 77
}
```

초기값을 반드시 적어야 하며, 초기화에서 타입이 분명할 때는 타입을 생략하고 `let x = 10;`처럼 적는 것도 가능합니다.

## 2. 지원하는 스칼라 타입과 명시적 `as` 형변환

공개 CLI에서 바로 쓸 수 있는 기본 스칼라 타입은 다음과 같습니다. (부동소수점 `f32`/`f64`는 일부러 빼 두어, 환경마다 계산 오차가 달라질 여지를 없앴습니다.)

| 타입 | 설명 | 주로 쓰는 곳 |
| --- | --- | --- |
| `i32`, `i64` | 부호 있는 정수 | 일반 계산, 큰 정수 |
| `u8`, `u32`, `usize` | 부호 없는 정수 | 바이트 값(`u8`), 배열 길이·인덱스(`usize`) |
| `bool` | 참/거짓 (`true`, `false`) | 조건식, 플래그 |

서로 다른 정수 타입을 섞어 계산할 수 없으며, 크기를 넓히는 변환은 `as`로 직접 적어 주어야 합니다.

```c
let u8 byte_val = 21;
let u32 wide = byte_val as u32;
let usize count = wide as usize;
let i64 big = byte_val as i64;
```

## 3. 연산자와 안전 검사 (오버플로·단락 평가)

- **사칙연산과 나머지**: `+`, `-`, `*`, `/`, `%`. 정수 범위를 넘거나(`overflow`) `0`으로 나누면(`zero_divisor`) 이상한 값이 나오는 대신 실행을 즉시 멈춥니다.
- **비트 연산**: `&`, `|`, `^`, `~`, `<<`, `>>` (`u8`, `u32`, `i32` 등에서 바이트 플래그 처리에 유용합니다).
- **논리 연산**: `&&`, `||`, `!` (`&&`와 `||`는 앞쪽 결과만으로 결론이 나면 뒤쪽 식을 실행하지 않는 단락 평가를 따릅니다).

```c
let u8 flags = 72;
let u8 selected = (flags & 127) | 5; // 77
```

## 4. 함수(`fn`)와 재귀 호출, `_ = expr;`

함수는 `fn 반환타입 이름(매개변수)` 형태로 선언하며 재귀 호출도 지원합니다. 반환값이 없는 도우미 함수는 `void`를 씁니다.

```c
fn i32 factorial(i32 n) {
    if (n <= 1) { return 1; }
    return n * factorial(n - 1);
}

fn void touch(ref mut i32 value) {
    *value += 1;
}
```

일반 함수가 돌려주는 값을 의도적으로 무시하고 싶다면 `_ = 계산식;` 형태로 명시해야 합니다.
